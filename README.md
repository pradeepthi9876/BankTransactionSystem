# BankTransactionSystem

A Java-based banking application that demonstrates account management, transaction processing, and exception-driven validation.

## Project Description

This project simulates a banking system where users can:
- create and manage accounts
- deposit and withdraw funds
- validate transaction amounts
- handle invalid operations using exception handling
- maintain balance integrity during business logic execution

## Features

- Account creation and balance tracking
- Secure transaction logic
- Custom exceptions for invalid operations
- Java-based object-oriented structure
- Beginner-friendly banking use case
